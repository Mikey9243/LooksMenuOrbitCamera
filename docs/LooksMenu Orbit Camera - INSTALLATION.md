# Installation

## Vortex
1. Vortex → Mods → **Install From File** → choose `LooksMenu Orbit Camera v1.4.4.zip`.
2. Enable the mod and let Vortex deploy.
3. Start Fallout 4 through F4SE (F4SE 0.6.23 for 1.10.163, F4SE 0.7.x for next-gen / anniversary) (`f4se_loader.exe`, or however you normally start it with F4SE).

There is no plugin (ESP) to enable.

## Updating from an earlier version
Disable or remove the old version in Vortex, then install 1.4.4. If you changed the INI, copy your changes over; the file has new comments but the same setting names.

## Manual
Copy the `F4SE` folder into `Fallout 4\Data`, so that you have
`Data\F4SE\Plugins\LooksMenuOrbitCamera.dll` and `Data\F4SE\Plugins\LooksMenuOrbitCamera.ini`.

## Uninstall
Remove the mod in Vortex (or delete the two files). Nothing is stored in your save, so it is safe to remove at any time.
